# README design notes

The [README](../README.md) introduces a runnable agent, gives readers a quick
local setup, and shows how to adapt it before the detailed architecture.

## Page structure

**Run it locally → Make it yours → How it works → Explore the features →
Read the code**.

- One opening animation makes the controller/turn separation tangible.
- Quickstart follows the opening, before the detailed architectural tour.
- Customization places `agent-config.ts`, coding-agent skills, and application
  patterns close to the first successful run. General skill installation stays
  visible; Claude Code plugin instructions live in a disclosure.
- Two further animations explain recovery and background conversation compaction.
- A compact feature table links to the deeper guides and execution diagrams.

The landing page uses three focused animations. The earlier, more detailed
execution timelines remain in `docs/images/` as reference material.

## Motion system

Each animation has three beats: establish the state, change one thing, and
show the consequence. Keep the spatial arrangement and main labels visible
throughout. Animate the current signal, progress, status, or compaction.
Hold the final state long enough to read it.

Purple identifies active control/context, green identifies acknowledged or
recorded work, and neutrals carry stable structure. Text and check marks also
convey meaning. Each animation includes a title and description, light/dark
palettes, and a reduced-motion final state.

Desktop assets are 800px wide, with 18–20px primary labels. Separate 380px mobile
compositions rearrange the diagram vertically instead of shrinking its text.
The README uses native `<picture>` elements to select the composition.

## Assets

Generated by `.misc/animations/landing.py`:

- `docs/images/landing-control.svg` and `landing-control-mobile.svg`
- `docs/images/landing-recovery.svg` and `landing-recovery-mobile.svg`
- `docs/images/landing-context.svg` and `landing-context-mobile.svg`

Each composition also has a `-still.svg` final-state asset. Explicit reduced-motion
`<source>` entries select these even when a browser does not forward that media
preference into an embedded SVG document.

Regenerate all twelve assets from the repository root:

```sh
python3 .misc/animations/landing.py
```

The assets use CSS animation inside self-contained SVGs: no scripts, external
fonts, image fetches, or runtime dependencies. The frame renderer in
`.misc/animations/render_frames.py` can inspect their 15-second cycles at
1.5, 7, and 12.5 seconds. See the [animation guide](../.misc/animations/README.md)
for maintenance instructions.

## Behavioral boundaries

- Steering preserves running tools; the next model step consumes the input.
- Recovery reuses recorded results; external effects can repeat when a crash
  precedes journaling.
- The compaction animation illustrates background conversation summarization.
  The page separately identifies blocking in-turn context compaction.
